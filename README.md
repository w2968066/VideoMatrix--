# VideoMatrix

![VideoMatrix 封面](docs/images/wechat-cover-21x9.png)

短视频矩阵自动化混剪工具。这个软件主要面向需要大量信息流素材、抖音千川素材、服装/电商花絮素材、Hook 测试素材的人，用来把原始片段自动裁剪、乱序拼接、加 BGM、加配音、加字幕、加水印，并批量导出多条视频。

它不是通用剪辑软件，也不负责调色、构图、美化画面。它更像一个“素材矩阵生成器”：把你已经预处理好的素材批量重组，解决人工纯混剪效率低的问题。

### v2.5.0 更新公告（2026-10-01）

#### 新功能与用法

- **三轨配乐**：全片 BGM、Hook BGM、Body BGM 可以同时使用。全片从视频开头播放，Hook 配乐只覆盖首段，Body 配乐从首段结束后播放；各轨独立设置音量、渐入渐出、循环或播完停止、播放起点及裁切重叠率。点击“＋Hook 配乐”“＋Body 配乐”添加，移除后保留设置供下次恢复。
- **按全片 BGM 时长**：只根据随机选中的完整全片音乐决定长度，不受 Hook / Body 配乐影响。Body 自动补齐或裁尾；Hook 已超过音乐时保留 Hook 并提示。成品 Hook 不会再改变已配置的配乐轨道。
- **可看内容的目录选择器**：选择文件夹时显示内部文件，支持系统原生缩略图、列表和详细信息；可按名称、修改时间、类型、大小排序，收藏常用目录，新建文件夹，前进、后退及刷新。
- **文件管理**：双击打开，右键支持定位、复制完整路径、改名及批量移入回收站。Ctrl / Command、Shift 用于管理多选，Body 素材仍以勾选框为准；F2 改名，Delete 移入回收站，F5 刷新。删除需确认，只使用系统回收站，不会降级成永久删除。

#### 修复与优化

- 修复选目录时无法确认里面的素材的问题；缩略图仅加载可见文件，不通过 FFmpeg 抽帧。
- 改名后同步软件内相关素材路径、输出路径、收藏与目录勾选；删除成功后移除相应引用。同名目标不会被覆盖，文件扩展名保留。
- 混剪运行或排队时禁止删改文件；后端状态无法确认时也会阻止操作。回收站部分失败会显示原因并保留失败项目。
- 修复目录切换后快捷键偶尔失效的焦点问题，并统一深浅色目录浏览样式。
- 兼容旧配乐配置：保留原音乐及音量；旧“仅 Body＋按 BGM 时长”会提示恢复按片段数量，选择全片音乐后可重新启用时长模式。

下载：[v2.5.0 正式版](https://github.com/w2968066/VideoMatrix--/releases/tag/v2.5.0)。详细用法：[三轨配乐](docs/bgm-three-tracks.md)、[目录浏览与文件管理](docs/directory-browser.md)。Windows 10/11 x64；macOS Apple Silicon ARM64。Mac 包未进行 Apple 开发者签名及公证，系统可能提示安全限制；完整桌面使用仍需 Mac 实机反馈。

### v2.4.0 更新公告（2026-09-28）

#### 新功能与用法

- **BGM 可选**：留空即可不加背景音乐，Hook / Body 原声和配音仍按各自音量设置输出；全部关闭时允许无声输出并提示。填入失效路径会报错，不会静默忽略。
- **按完整 BGM 时长混剪**：选择 BGM 后点击“按 BGM 时长”，每条输出随机选一条完整音频，只有一条就使用该条，从头播放到尾。Body 超长自动裁尾，不足按组顺序继续随机补齐，生成日志说明调整；素材不足会提示，不无限重复同一切片。输出数量仍由“数量”决定。
- **保持成品 Hook 保护**：BGM“Body 开”时，总时长为 Hook + BGM；“Body 关”时以 BGM 作为全片目标时长。Hook 已达到或超过 BGM 时保留 Hook、不追加 Body，并提示音乐覆盖情况，仍可生成。插入随机首帧会额外增加一帧并后移音频。
- **完整 Body 原片**：普通 Body 后段及每个分组均可勾选“按原素材时长”，随机使用完整视频；忽略对应固定秒数和裁切重叠率，段数保留。不同组可混用完整原片与固定秒数；按 BGM 时长生成时尾段仍会裁短对齐音频。界面显示预计时长范围，实际时长写入日志。
- **内置帮助**：“联系我”左侧新增“简易教程”，涵盖普通、分组、完整音乐、成品 Hook 和多款批量用法；各主要设置旁的小问号可点击查看说明，支持 Esc 和点击外部关闭。
- **输出默认值**：1080×1920、8000k、30 fps、GPU 勾选；已有保存的参数不强制覆盖。随机首帧旁新增红色“建议打开”，仍为独立可选功能。

#### 修复与优化

- 修复浅色模式下路径、参数、分组输入框及消息提示仍为深色的问题。
- 修复查看历史日志时被新日志强制拉回底部：向上滚动后保持位置，手动回到底部恢复跟随，切换标签也保留阅读位置。
- Hook、普通 Body、分组 Body 的原素材时长开关统一为勾选框；BGM、配音、字幕、水印统一用小号橙色“可选”标注。
- 清空 BGM 自动恢复按片段数量生成，保留原手动参数；未选择 BGM 时点击时长模式会提示并定位到路径输入框。
- 成片变换按实际 Body 时长处理，避免完整原片及音频裁尾后仍沿用固定段长。没有 Body 时跳过仅作用于 Body 的字幕、配音、水印处理。

下载： [v2.4.0 正式版](https://github.com/w2968066/VideoMatrix--/releases/tag/v2.4.0)。Windows 包面向 Windows 10/11 x64；macOS 包为 Apple Silicon（ARM64），不是 Intel 通用包。macOS 较旧系统兼容性未完整验证。

## v2.3.0 更新公告（2026-09-21）

### 按原素材时长使用 Hook

- 新增“按原素材时长”开关，开启后 Hook 文件整段作为首段参与混剪，不再按固定秒数裁切。适合 Hook 文件夹中的视频长度不一致、希望逐条保留原始开头的场景。
- Hook 按随机顺序轮换，一轮内每个文件使用一次；用完后重新洗牌开始下一轮。并发渲染也遵循每轮不重复。
- 开启时首段时长输入框置灰，Hook 重叠率固定为 `1`；关闭后恢复原首段时长和重叠率设置。
- 普通和 Body 分组模式均适用。成片长度随选中的 Hook 改变，界面读取 Hook 原素材时长并显示预计成片时长范围。
- 字幕、BGM、配音、水印及成品 Hook 保护的起始位置均按本条实际 Hook 时长计算。

### 界面说明与修复

- 重叠率问号弹窗改为解释“原素材的裁切重叠率”，用 0% 和 30% 示例展示切片起点及复用区间，图例和说明分开展示。
- 顶部联系方式默认隐藏微信号，可通过眼睛图标显示或收起。
- 增大窗口最小高度，输出参数在默认窗口中可见。

### 使用方法

1. 选择包含多个 Hook 视频的文件夹，并按正常方式设置 Body、BGM 和其他参数。
2. 勾选 Hook 时长旁的“按原素材时长”。首段固定时长会停用，Hook 重叠率设为 `1`。
3. 确认界面显示的预计成片时长范围，然后启动渲染。
4. 软件随机轮换完整 Hook；每一轮使用完文件夹中的全部 Hook 后，再重新随机排序。

## v2.2.0 更新公告（2026-09-11）

- Body 支持普通 / 分组两种模式；分组模式最多 4 组，每组独立选择文件夹、设置抽取数量和单片段时长。

## 适合谁

适合：

- 需要大量短视频素材做信息流投放的人。
- 需要批量测试不同 Hook、不同卖点排序的人。
- 有很多服装、产品、模特花絮、口播、细节镜头素材的人。
- 希望把 1 条素材拆成多条“结构不同”的素材用于测试的人。

不适合：

- 只想做单条精剪视频的人。
- 需要复杂转场、精细包装、调色、特效设计的人。
- 没有大量乱序拼接需求的人。

## 它能做什么

```mermaid
flowchart LR
  A["预处理好的素材片段"] --> B["Hook / Body 切片"]
  B --> C["随机组合"]
  D["BGM / 配音 / 字幕 / 水印"] --> E["合成"]
  C --> E
  E --> F["批量导出矩阵视频"]
```

主要能力：

- 批量裁剪视频片段。
- Hook 首段和 Body 后段分开管理。
- 自动乱序拼接，生成多条不同组合的视频。
- 支持同文件夹纯混剪。
- 支持 Hook 和 Body 分文件夹组合。
- 支持总文件夹下多子文件夹批量处理。
- 支持 BGM、配音、字幕、水印，包括 GIF 水印。
- 支持成品 Hook 模式，可让 BGM、配音、字幕、水印只从 Body 段开始生效。
- 支持 Hook 与 Body 分别设置原声音量，也支持直接使用视频文件的声音作为 BGM。
- 支持 GPU 加速。实际速度取决于素材、分辨率、显卡和并发设置。
- 支持预检产能和智能压测。
- 支持历史记录，避免重复使用已经用过的片段。
- 支持可选成品变换层：混剪完成后对最终成品进行构图、色彩、锐度、相邻帧及音频微调，并保持总时长、分辨率和帧率不变。
- 支持 Codex 等 Agent 打开软件、识别并填写 Hook / Body / BGM 等路径和混剪参数。

### 成品变换层

“去重变换”位于右侧独立页签，默认关闭，不改变原有混剪流程。开启后，软件先按原逻辑完成混剪，再处理最终成品；不会修改 Hook、Body 等源素材。

- 默认档位为“标准”，也可选择“轻度”或“增强”；界面会显示各档位说明。
- 每个输出及其内部片段使用独立随机参数。
- 相邻帧混合只使用这条成片自身的帧，不引入外部素材。
- 处理成功后才替换成片；处理失败会保留原成片并在日志中提示。
- Windows 文件短暂占用时会自动重试，临时文件不会作为额外视频产出。

## Agent 工作流

仓库包含独立的 `agent_adapter` 适配层和 VideoMatrix Skill。它们只调用现有桌面程序与后端，不另写混剪核心。

默认采用半自动模式：Agent 只打开 VideoMatrix，并把用户明确提供的素材路径和参数合并到软件上次设置；不会自动点击预检或开始渲染。只有用户明确要求“预检”或“直接开始”时，Agent 才会执行相应动作。

支持自然语言换算视频结构。例如：

```text
这个目录是 Hook，那个目录是 Body，整条 12 秒，首段 3 秒，使用默认配置打开软件。
```

适配层会填写 Hook `3` 秒、Body `1.8` 秒、总片段数 `6`，并使用竖屏 2K、`8000k`、`24fps`；用户检查后再手动开始。省略“使用默认配置”时，软件原有的时长、音量、分辨率和并发等设置保持不变。

一键接入本机 Codex：

```powershell
PowerShell -ExecutionPolicy Bypass -File agent_adapter/install_codex.ps1
```

详细命令与 MCP 工具见 [`agent_adapter/README.md`](agent_adapter/README.md)。

## 使用前预处理

软件只负责裁剪、拼接、加 BGM、加配音、加字幕、加水印。原素材建议先在剪映或其他剪辑软件里预处理。

推荐流程：

1. 设置草稿分辨率和帧率，例如 `1080*1920`、`30` 帧。
2. 把所有素材片段拖进时间线。
3. 完成调色、画面大小、构图、基础包装等处理。
4. 全选时间线片段。
5. 右键导出所有片段。
6. 注意不是导出整条时间线，而是导出每个片段。

这样得到的素材更适合交给 VideoMatrix 批量混剪。

## 核心概念

### Hook

Hook 是视频开头片段。一般短视频前 2 到 3 秒不一样，对很多投放场景来说就已经是不同的视频结构。

Hook 值可以理解为相邻切片之间允许重叠的比例：

![Hook 值说明](docs/images/hook-value-overlap-21x9.png)

- Hook 值越大，相邻片段重叠越多。
- Hook 值越大，可切出的独立片段数量越少。
- Hook 设置为 `1` 时，接近重复使用模式，适合固定强 Hook 去搭配不同后段。

### Body

Body 是后段素材。它负责承接 Hook 后面的内容，可以是卖点、产品细节、花絮、场景、模特动作、口播辅助画面等。

Body 会在单条成片内部尽量避免重复画面，但跨视频可以复用，适合大量组合。

### 成品 Hook

如果 Hook 文件本身已经带有 BGM、配音、字幕或水印，可以打开“成品 Hook”模式。开启后，Hook 段保留原始声音和画面，BGM、配音、字幕、水印从 Body 段开始生效，避免重复叠加。

这类 Hook 文件应当提前按最终输出的分辨率和帧率导出。首段时长设置为素材实际视频轨时长或更短，软件会保留尾部安全边距并允许刚好够长的整段素材使用。

## 用法 1：纯混剪

用于解决素材量不足的问题。

设置方式：

- Hook 和 Body 共用同一个文件夹。
- 把原来的多个片段自动调换顺序。
- 一条素材可以扩展出多条不同组合的视频。

适合场景：

- 服装类目拍了很多段模特花絮。
- 产品细节、场景素材、空镜素材比较多。
- 想快速生成几十条或上百条素材。

建议：

- Hook 重叠率可以从 `0` 或 `0.1` 开始。
- Body 重叠率不要太高，`0.3` 通常已经偏高。
- 重叠率越高，重复利用的片段越多，素材差异会变小。

多款处理：

- 每个款式单独放一个子文件夹。
- 再把这些子文件夹放到一个总文件夹。
- 软件选择总文件夹后会自动处理所有子文件夹。
- 导出结果也会按 Hook 子文件夹分类。

## 用法 2：不同 Hook 搭配后段

用于解决不同开头素材的拼接工作。

设置方式：

- Hook 和 Body 使用不同文件夹。
- Hook 放你要测试的开头。
- Body 放后段素材或卖点素材。
- Hook 重叠率设置为 `1`，让强 Hook 可以重复搭配不同后段。

适合场景：

- 你有多个不同开头，需要快速产出测试素材。
- 后段只是卖点排序或产品画面，变化要求没那么高。
- 一个 Hook 需要生成 10 条、20 条不同后段组合，用来提高测试机会。

目的：

- 给强 Hook 配足够的素材。
- 避免只有一条素材导致 Hook 再好也不一定排得上流量。
- 快速测试不同后段承接方式。

## 用法 3：水印、字幕、配音

水印、字幕、配音都有独立路径。

可结合上面两种用法使用：

- 加品牌水印。
- 加 GIF 动态水印。
- 加字幕文件。
- 加讲解配音。
- 加 BGM 或调整原声音量。

## 路径说明

- Hook、Body、BGM、配音、字幕、水印、输出目录都有独立路径。
- Hook 和 Body 支持总文件夹下子文件夹分类。
- 多款素材建议按子文件夹整理。
- 导出会按 Hook 子文件夹分类。
- 输出目录不是必填，不填会使用默认输出逻辑。

## 设置说明

### 历史记录

软件会记住哪些 Hook 片段用过。没剪完下次继续时，它会尽量避开已经用过的片段。

不要随便点“清除记录”。清除后，之前用过的片段会重新进入可用池。

### 预检产能

点击预检产能后，软件会按当前参数估算最多能剪出多少条。

如果你设置的生成数量超过可用产能，开始渲染时会按预检产能自动降低，避免强行生成失败。

### 智能压测

智能压测会测试当前电脑在不同并发数下的渲染速度，并给出建议并发。

这个结果和当时电脑剩余性能有关。如果你同时开了很多软件，压测结果会变低。

### GPU

开启 GPU 后会优先调用 NVIDIA 硬件编码。是否能明显加速取决于显卡、素材规格、分辨率和并发数。

例如 12 秒视频素材在合适配置下可以做到几秒生成一条，但这不是固定承诺。
