# VideoMatrix 2.4.0

## 新功能

- BGM 改为可选，留空不添加背景音乐，原声与配音独立控制。
- 按完整 BGM 时长混剪：每条输出随机选一条完整音频；普通 / 分组 Body 自动补齐或裁尾，日志说明调整。只作用于 Body 时总时长为 Hook + BGM；全片生效时以 BGM 为目标。Hook 已超过音乐则保留 Hook 并提示，仍可执行。
- 普通 Body 和每个分组均支持“按原素材时长”，可与固定秒数组混用。按音乐时长模式的最后一段仍会对齐裁尾，素材不足时明确提示。
- 新增简易教程与可点击问号说明。
- 新用户默认输出 1080P、8000k、30 fps、GPU 开启；保留已有用户设置。随机首帧旁新增红色“建议打开”，不会强制开启。

## 修复

- 浅色主题输入框、分组参数及提示框颜色。
- 向上查看日志时不再被自动拉回底部，回到底部后恢复跟随。
- 统一 Hook / Body 原素材时长勾选样式，小号橙色可选标注。
- 清空 BGM 后自动恢复片段数量模式；未选 BGM 时点击音频模式给出提示。
- 成品变换沿用实际片段时长；无 Body 时跳过仅 Body 生效的字幕、配音、水印。

## 使用方法

1. 设置 Hook 和 Body；Body 可普通随机混剪，也可按 1～4 组顺序拼接。
2. 不需要配乐时留空 BGM；需要完整音乐时选择 BGM 并点击“按 BGM 时长”。
3. 需要保留完整片段时勾选对应“按原素材时长”，然后预检并启动渲染。
4. 右上日志查看素材不足、裁尾、补齐和 GPU 降级原因。

## 安装包

- Windows 10/11 x64：`VideoMatrix.Setup.2.4.0.exe`。
- Apple Silicon macOS ARM64：`VideoMatrix.Setup.2.4.0-mac.dmg`，不是 Intel 通用包；旧版 macOS 兼容范围未完整验证。
- 均内置后端与 FFmpeg，无需单独安装 Python。macOS 包未经过 Apple 公证，系统可能显示安全提示。
- 本次不承诺平台原创标签、AI 识别或首帧封面规则；随机首帧与画面变换均为独立可选功能。
