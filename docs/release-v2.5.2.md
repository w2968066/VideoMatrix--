# VideoMatrix 2.5.2

## 新增功能

- **任务单独停止**：右侧“任务”页中，每个等待或运行任务新增“停止”按钮，只停止该项，不影响其他任务；已完成视频保留，全局停止继续可用。
- **完整流程压测**：固定同一批最多 8 条素材组合，在实际输出盘测试 1–4 路并发，包含当前开启的成品变换与随机首帧。先预热，再复测最多两个最快稳定档位，按整批完成时间推荐；耗时相差 5% 以内优先较低并发。
- **真实进度与结果**：压测作为独立任务显示真实进度，可在任务页单独停止。成绩区分同批总耗时、每分钟产量及单条实际平均耗时；后处理失败、硬件降级、有效并发下降或样本不足 8 条时，不使用不可靠结果自动调整并发。

## 修复与优化

- 修复随机首帧抽到靠后画面时缓存大量前段帧的问题，改为独立定位取帧，降低高分辨率并发内存峰值。
- GPU 编码增加跨任务统一并发预算。暂时 CUDA / 资源错误先等待在途编码释放，再有限单路重试；必要时降低并发或回退 CPU，避免一次临时失败让后续持续降级。
- 瞬时探测失败不再长期缓存为显卡不可用；硬件速度测量不再计入等待时间，改善编码器选择。
- 加速日志优先展示具体失败根因，完整 FFmpeg 错误保存在用户配置目录的 `VideoMatrix/logs`，最多保留 20 份。
- 日志区分基础混剪、后处理与最终完成。后处理失败或停止时保留可用基础成片，在“产出”页标明警告；任务区分全部完成、部分完成和失败。
- 随机首帧探测支持超时和取消；替换首帧不增加帧数，插入首帧仍增加一帧并整体后移音频。
- 修正压测实际并发统计及会话释放；安装包仅包含正式程序文件，排除开发截图、测试日志等文件。

## 使用说明

1. 正常设置素材、输出盘、GPU 和后处理选项。
2. 当前没有生产任务时，点击“智能压测”。完整测试最多执行 49 次渲染，会比旧版耗时更长；右侧“任务”页可查看进度或停止。
3. 测试会隔离素材使用记录，临时样片在结束后清理，不计入正式产出。压测期间不能启动生产任务。
4. 获得稳定完整复测结果后，软件自动应用建议并发；停止、失败或数据不足时保留原设置。

较高并发可能提高整批产量，却不一定缩短单条视频的实际耗时。GPU 是否可用以本机探测为准，解码和软件滤镜仍可能使用 CPU；建议并发受素材、参数及当时设备负载影响，不保证所有设备都适用。

## 安装包

- Windows 10/11 x64：`VideoMatrix.Setup.2.5.2.exe`
- macOS Apple Silicon ARM64：`VideoMatrix.Setup.2.5.2-mac.dmg`

macOS 包未进行 Apple 开发者签名及公证，系统可能提示安全限制；完整桌面使用仍需 Mac 实机反馈。安装新版保留已有设置与素材记录。

本版包含未单独公开发布的本地 2.5.1 修复。
