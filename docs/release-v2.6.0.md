# VideoMatrix 2.6.0

## 新增功能

- **随机分辨率**：在“输出”勾选，设置短边上下限，保持当前分辨率的宽高比；默认 1080–1440 px。软件从范围内宽高均为偶数的合法尺寸中随机选择，每条抽一次，允许重复。关闭恢复固定分辨率，不改变帧率。
- **随机码率**：独立勾选并设置范围，默认 8000–14000 kbps，每条抽一次，允许重复。关闭恢复原固定码率。随机尺寸与码率独立于画面变换，不影响原素材抽取；GPU 探测按尺寸范围上限检查，封面、变换和失败重试沿用本条参数。
- **画面变换 V2**：默认关闭，与混剪共用一次编码，不修改源素材，不添加扫描或报告。可单独选择 Hook / Body，以及微裁切、轻微色彩、允许随机镜像。轻度 / 标准 / 增强的微裁切上限分别为每方向两侧合计 0.5% / 1% / 2%；色彩勾选后随强度调整，镜像会翻转源画面文字与 Logo。
- **B 画面混合**：可选择一个视频，设置 1%–15% 不透明度；短素材可循环、定格末帧，或跳过混合并提示。B 视频声音不参与输出。默认关闭，开启会增加解码与滤镜耗时。

## 修复与优化

- 随机首帧从本条实际选中的素材裁切区间取帧，并入主混剪；正常路径仅一次视频编码，不再整片后处理转码。替换模式保留原音频和时长，插入模式新增静音首帧，原音画同步后移。
- 修复 Windows 上取帧进程与软件保活管道冲突，封面已经写出但进程卡住、最终等待 30 秒超时的问题。取帧关闭交互输入，渲染子进程显式隔离 stdin；不通过延长等待或隐藏警告解决。
- 编码前独占预留唯一正式文件名，直接生成 MP4，完成后不再改名、覆盖或搬运，修复 Windows 提交视频时的文件占用报错；输出目录不再留下逐条 `.vm-*` 文件夹，同名并发任务不会覆盖旧结果。
- 只有编码成功的文件才加入产出列表；失败或停止只清理本次未完成文件，已完成结果保留。封面或画面变换异常仍有提示，并有限回退保留可用基础成片。
- 视频和原声音轨分别读取，避免长 Hook 拼接高分辨率、高帧率 Body 时为读取音频而提前缓存大量解码帧。保留时间线和原音轨，不增加视频转码。
- 随机分辨率下水印等比适配，字幕保持相对位置与字号；软件新增的字幕、水印在画面变换后叠加。三轨配乐、分组 Body、完整原片和按全片 BGM 时长继续支持。
- 旧配置自动补齐新字段，随机输出默认关闭，旧高开销帧混合不再自动启用；用户素材、路径及使用记录保留。

## 使用说明与边界

1. 只需普通混剪时，保持随机输出和画面变换关闭即可。
2. 需要不同输出规格时，在左侧“输出”勾选随机分辨率或随机码率，并填写范围；范围设置会保留。
3. 需要画面变化时，打开右侧“去重变换”，选择范围与效果；B 画面混合仅按需启用。
4. 随机首帧仍是独立开关，可选择替换或插入。封面不包含软件后加的字幕、水印和画面变换，以效率优先。

这些功能不保证平台判定“首发”“不重复”或改变 AI 标识。正常路径共用一次编码，故障重试仍可能增加耗时；性能取决于素材、机器负载、输出参数及效果。非整帧素材边界存在帧率量化，不承诺任意输入组合的帧数逐帧完全一致。

本地发布前后端回归 134 项及 74 个子测试通过；真实失败素材的封面取帧修复复验 6/6 成功。性能与复现记录见 [验证记录](fused-cover-validation.md)，不将个别素材的加速比例作为通用保证。

## 安装包

- Windows 10/11 x64：`VideoMatrix.Setup.2.6.0.exe`
- macOS Apple Silicon ARM64：`VideoMatrix.Setup.2.6.0-mac.dmg`

macOS 包未进行 Apple 开发者签名及公证，系统可能出现安全限制；完整桌面使用仍需 Mac 实机反馈。本版不包含实验扫描/治理界面。
