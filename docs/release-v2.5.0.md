# VideoMatrix 2.5.0

## 新增

- 三轨配乐：全片、Hook、Body BGM 可同时叠加，独立设置音量、渐入渐出、循环、播放起点与裁切重叠率。
- “按全片 BGM 时长”明确只由完整全片音乐决定视频长度，Body 自动补齐或裁尾。
- 目录浏览支持系统原生缩略图、列表、详细信息、名称/时间/类型/大小排序、常用目录收藏及新建文件夹。
- 文件管理支持双击打开、右键菜单、定位文件、复制路径、重命名、批量移入系统回收站及常用快捷键。

## 修复与优化

- 选文件夹时可以查看内部素材；缩略图按可见范围加载，不通过 FFmpeg 抽帧。
- 改名、删除后同步软件内素材、输出、收藏与目录勾选引用；扩展名保留，同名项目不覆盖。
- 删除需确认，只走系统回收站；混剪运行/排队或后端状态不可确认时禁止删改。
- 修复目录导航后的快捷键焦点问题；目录浏览适配深浅色主题。
- 成品 Hook 不再联动改变配乐；旧配乐设置迁移保留路径和音量。旧“仅 Body＋按 BGM 时长”会提示恢复按片段数量，可选全片音乐后重新启用。

## 快速使用

1. 原混剪流程保持不变；需要分区配乐时点击“＋Hook 配乐”“＋Body 配乐”，展开各轨设置。
2. 需要保留完整音乐时选择并启用全片 BGM，再点“按全片 BGM 时长”。
3. 点击路径旁浏览按钮即可查看目录内容；Body 素材使用勾选框，文件管理使用点击/Ctrl/Shift 选择。
4. F2 改名，Delete 移入回收站，F5 刷新，Alt+左右方向键前进后退。

## 安装包

- Windows 10/11 x64：`VideoMatrix.Setup.2.5.0.exe`。
- Apple Silicon macOS ARM64：`VideoMatrix.Setup.2.5.0-mac.dmg`，非 Intel 通用包。
- 内置后端、FFmpeg/FFprobe 和思源黑体，无需单独安装 Python。
- macOS 未进行 Apple 开发者签名及公证，可能遇到系统安全限制；完整桌面使用及旧系统兼容仍需 Mac 实机验证。
