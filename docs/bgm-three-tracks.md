# 三轨配乐（v2.5.0）

全片 BGM、Hook BGM、Body BGM 可分别选择文件或目录并独立启用。每条成片从每个目录随机抽一条音乐；单文件固定使用。三轨同时叠加，原声与配音独立，最终混音使用峰值保护。

| 轨道 | 视频中的生效区间 |
| --- | --- |
| 全片 BGM | 从 0 秒到成片结束 |
| Hook BGM | 从 0 秒到实际 Hook 结束 |
| Body BGM | 从实际 Hook 结束到成片结束 |

默认只显示全片轨道，点击“＋Hook 配乐”“＋Body 配乐”增加轨道。各轨设置提供音量、渐入渐出、音乐不足时循环补齐或播完停止、从音乐开头或随机裁切点播放、裁切重叠率。

- 长音乐裁尾，短音乐默认循环补齐。淡化作用于整个播放区间，循环处不重复淡化。
- 淡入与淡出合计超过实际播放长度时按比例缩短，并记录日志。
- 无 Body 时跳过 Body 配乐。移除轨道会停用，保留路径与设置，重新添加可恢复。
- “按全片 BGM 时长”只依据随机选中的完整全片音乐。全片音乐从头播放一次，裁切与循环设置暂不生效；Hook / Body 音乐不决定视频长度。
- 全片音乐可为 0% 音量但仍决定时长；停用或清空全片轨道则恢复按片段数量。
- 普通 / 分组 Body 自动补齐或裁尾；完整素材模式下末段仍可能裁尾。Hook 长于音乐时保留 Hook 并提示，不循环全片音乐。插入随机首帧额外增加一帧。
- 成品 Hook 是独立默认设置快捷方式，默认把 Hook 原声设为 100%，配音、字幕、水印仅作用于 Body；不修改已配置的三条音乐。

## 旧配置迁移

旧全片配乐迁入全片轨道；旧仅 Body 配乐迁入 Body 轨道。保留路径、音量与裁切重叠率。旧版默认随机裁切点继续保留。

旧“仅 Body＋按 BGM 时长”恢复按片段数量，首次启动显示提示并记录日志；音乐与音量保留。选择全片音乐后可重新启用按全片 BGM 时长。

## 验证

后端测试使用不同频率的真实音频渲染并分析输出，检查全片音乐、Hook 结束边界、Body 起点、短音频循环、播完停止、淡化缩短、额外配音输入映射、静音全片决定时长及无 Body 的情况。前端检查三轨操作、成品 Hook 状态、一次性迁移提示和深浅色主题。
