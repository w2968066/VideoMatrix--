# Body 分组与随机首帧

## Body 分组

在 Body 素材区切换“普通 / 分组”。普通模式继续使用原来的 Body 目录、后段时长和总片段数。

分组模式最多配置 4 组，各组独立启用并选择素材文件夹，设置抽取片段数和单片段时长。输出按 Hook → Body 1 → Body 2 → Body 3 → Body 4 排列，组内随机抽取；未启用组跳过。多个 Hook 子库使用同一套已指定的组目录。

总片段数 = 1 + 各启用组的片段数量之和。

预计总时长 = Hook 时长 + 各启用组的（片段数量 × 单片段时长）之和。实际时长受输出帧率的帧边界影响。

组目录不存在、没有合适的视频或可用切片数量不足时，程序明确提示对应组。不同组允许指向同一个素材目录。

## 随机首帧

输出区域的“随机首帧”是独立开关。每条成品从自身随机抽取一帧、随机缩放裁切，不产生配套 JPG。若开启成品变换，首帧处理在变换后进行。

- 替换首帧（默认）：替换原视频第一帧，音频和总时长不变。
- 插入一帧：在原视频前加入封面帧，原画面和音频一起后移一帧，总时长增加 `1 / 输出帧率` 秒。例如 24fps 增加约 0.0417 秒。

播放开头可能看到短暂的画面切换。抖音是否采用该帧作为默认封面，需要以实际发布入口的结果为准。

普通和分组模式均可使用此开关；它与“去重变换”开关互不依赖。
