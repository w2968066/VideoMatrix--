# 去重变换层 V2：集成与验收说明

版本：v2.6.0。以独立的画面变换模块提供可选效果，不承诺平台的去重、AI 检测或“首发”判定。

## 与 handoff 的取舍

参考 `DEDUP_LAYER_HANDOFF.md`（2026-10-02），沿用独立配方、明确输入输出、固定种子、显式 B 素材/占比/结束策略、原片保护和错误隔离。保持此前产品要求：只变换并输出，不默认增加前后检测、候选筛选、SQLite、pHash 或报告。

“独立层”是职责和接口独立，并非每条视频必须再编码一次。生产流程在原片段归一化时融合变换，避免旧实现对整片做 split/trim/concat、音频重处理和大规模帧缓冲。

```text
原有选材 / 普通或分组 Body / 实际时长 / BGM 规划（不变）
  → 原有每段 scale/crop + 可选变换配方
  → 原有拼接 → 可选 B 画面混合 → 原有字幕 / 水印
  → 可选随机首帧合成 → 原有音频混合与一次编码
```

没有新增扫描页面，也不产生额外候选视频。随机首帧仍是独立开关，但已从本条实际素材区间抽一帧，合并主编码，不再整片二次转码；封面不含软件后加的字幕、水印或变换效果。

## 默认值与开关

| 项目 | 行为 | 性能/画质边界 |
| --- | --- | --- |
| 总开关 | 默认关；关闭不构建配方、不探测 B 素材 | 保持原混剪滤镜/选材路径 |
| 微裁切 | 默认开；轻度/标准/增强上限 0.5%/1%/2% | 每个轴两侧合计的额外裁切，不是单侧；原先适配输出比例的裁切不计入；仍只有一次缩放 |
| 色彩变化 | 默认关，用户勾选后按强度变化 | 额外逐像素计算，可能影响商品颜色 |
| 随机镜像 | 默认关；允许后每段按固定种子随机决定 | 会翻转原素材已烧录的文字/Logo；不翻转稍后添加的字幕水印 |
| B 画面混合 | 默认关；选择一个本地 SDR 视频，默认 3%，可调 1%–15% | 新增一路解码、缩放和混合；仅映射主片声音，不能承诺肉眼无变化 |
| B 时长不足 | 循环 / 定格末帧 / 跳过并提示 | 主片决定结束，不使用 shortest 截断主片 |
| Hook / Body 范围 | 各自开关，使用本次实际选择的段长 | 兼容原素材时长、分组、按全片 BGM 时长裁补 |

旧版 `variant_frame_mix` 只保留输入兼容，V2 不执行；不默认叠加旋转、噪声、锐化、抽帧、变速、音频重采样或音调变化，也不随机清除/伪造元数据。

B 视频在整条主时间线的 0 秒开始播放，再按 Hook/Body 开关限制混合区间；仅 Body 生效时不是重新从 B 的第 0 秒开始。仅 Hook 模式也按主片总长检查“素材不足/跳过”策略。需要不同对齐方式可另加选项，不隐式猜测。快速元数据无法确定视频轨时长且选择“跳过”策略时，会提示并跳过 B；不把较长音轨的容器总长当成视频长度，也不为此全片扫描。循环/定格按实际视频 EOF 处理。

## 模块与兼容

- `dedup_plan.py`：纯函数、冻结数据结构、私有 `random.Random(seed)`；只返回配方和单段视频滤镜，不操作文件，不调用主选材 RNG，不启动进程。
- `dedup_blend.py`：可选 B 视频输入及过滤链；选择非附带封面的真实视频流，明确不映射其音频。
- `video_matrix.py`：很薄的宿主适配。沿用现有选材、音轨、字幕、水印、GPU 会话和并发调度；B 探测按路径/修改时间/文件大小缓存，不在每个输出重复探测。
- `video_variant.py`：保留旧 `process()` 与封面所需进程/替换/种子接口，新增 `process_to_file(input, output, config, seed, ...)`。旧 `inline_filters()` 已显式停用，防止无意重新引入整片拆分图。
- `TaskService`：已融合标记防止二次变换；失败提示传入产出列表，不把回退结果谎报为全部功能成功。

随机种子命名空间保留旧值，避免无关地改变随机首帧抽样；配方版本单独升级到 `creative-variant-v2`。相同种子与相同配置可得到相同配方，不承诺不同 FFmpeg/显卡/编码器输出字节相同。

独立文件接口保留输入，先写同目录自有临时文件，校验尺寸/时长/音轨，再原子提交且不覆盖已有目标；失败、取消则清理自有临时文件。原子提交使用同文件系统硬链接，不支持时明确失败，不退化为覆盖用户文件。兼容 `process()` 仅供宿主传入已生成的可替换成片。

独立文件接口最多 32 段、每路 2 解码线程，使用独立 seek 输入避免整片多路 split 缓冲；音频原样复制，不主动转码。未配置时间线时处理整个文件，未指定尺寸时用源画面显示尺寸（90°/270°手机旋转标记会交换宽高，并清零输出方向避免二次旋转）。当前明确不支持独立文件接口的 B 混合及 HDR；桌面混剪的 B 混合由宿主集成，不受此接口限制。音频不能直接装入 MP4 时明确失败而不暗改编码。

## 保护、失败和性能边界

- 原素材从不覆盖。没有自动主体识别、文字识别或人脸保护模型。
- 可选内部参数 `variant_protected_regions` 使用原有画幅适配后的输出坐标（0–1），支持 `x/y/width/height/start/end`。它只保护裁切边界、抑制相关段镜像，不代表该区域像素完全不变，也不豁免色彩/B 混合；暂未增加 UI 编辑器。
- 变换位于新字幕、水印之前；成品 Hook 自带的字幕 Logo 仍属于原画面，需关闭镜像或相应作用范围。
- B 无效时跳过 B 并提示，其他可用变换和基础混剪继续。配方无效时跳过本条变换。变换实际渲染失败后，使用完全相同的选材、配音、BGM、字幕、输出路径重试一次基础混剪；不会重新随机选材，也不再重复变换。
- 停止操作会终止当前进程，不触发基础混剪重试。探测有超时并加入原有进程追踪。
- 回退不是零成本：第一次编码已消耗的时间无法回收。成功回退会在日志和产出中提示；基础编码也失败则该条失败，不伪造成功。
- 微裁切仍改变缩放目标尺寸；即使不增加编码次数，也可能有 CPU/显存和时间波动。色彩与 B 混合成本更高。共享原有硬件编码会话，不另开一套 GPU 并发池。
- 宿主原有 SDR/yuv420p 输出策略不因本次改造而扩展为 HDR 色彩管理；HDR 输入不在本次无损画质承诺范围。可选 B 和独立文件接口对已识别的 HDR 明确拒绝。

## 验证

新增 `test_dedup_plan.py`、`test_dedup_renderer.py`、`test_dedup_integration.py`；两端 CI 纳入这些用例。覆盖配方可复现/独立 RNG、微裁切边界、保护区域、关闭旁路、单次编码、没有额外整片 split、分组实际时长、主片音频包一致、帧数/时长、B 循环/定格/不足跳过、附带封面选流、中文路径、源文件/已有目标不变、失败同选材回退、取消不重试和产出警告。

继续运行既有 BGM、音频时长、完整 Hook、分组 Body、随机首帧、字幕、GPU 恢复、压测和启动回归。前端测试验证旧配置迁移、开关不重置参数、取消选择文件、请求规范化及新控件。

V2 首轮本地验证：后端与 Agent 适配器共 **102 项测试 + 39 个子场景通过**；前端 **17 项 runtime 测试通过**，完整 UI smoke 与 Vite 构建通过。包括真实 FFmpeg 验证短 B 画面/长 B 音轨的循环和定格，以及手机旋转标记、三轨 BGM/配音/字幕/水印共存。

v2.6.0 发布前验证：后端与 Agent 适配器 **134 项测试 + 74 个子场景通过**，前端 **21 项 runtime 测试及 Vite 构建通过**。新增随机输出与首帧合并验证见 [随机首帧验证记录](fused-cover-validation.md)。两端发布构建以 GitHub Actions 实际结果为准，CI 不代表 Mac 完整桌面真机使用已验收。

性能用隔离生成素材比较关闭、默认微裁切、可选 B 混合；结果只代表测试设备与素材，不外推到所有用户。未实测的平台不宣称已验证。

### 本机性能记录（2026-10-02）

Windows 11、本机 `h264_nvenc`、1920×1080、30fps、8000k、6 秒、Hook 1 秒 + 5 个 Body 各 1 秒、并发 1。每档预热一次，随后交错各测三次；固定选材/种子。随机首帧关闭。仅合成素材，没有使用用户生产素材。

| 模式 | 三次整体渲染耗时（秒） | 中位数 |
| --- | --- | --- |
| 关闭变换 | 1.221570 / 1.188600 / 1.404191 | 1.221570 |
| 默认微裁切 | 1.249801 / 1.245692 / 1.240836 | 1.245692 |
| 微裁切 + 3% B 混合 | 1.509859 / 1.506749 / 1.615841 | 1.509859 |

默认档中位耗时约增加 2%，B 混合约增加 24%；样本少且存在波动，不能当成通用性能承诺。所有输出均为 6 秒 / 180 帧、同一个 NVIDIA 编码器、同一选材顺序；音频包哈希一致、原素材哈希不变。B 混合使用原生 `normal/all_opacity` 加权，不使用逐像素表达式解释器；对应像素回归允许 SIMD 舍入带来的 1 级亮度/色度差。

复测：`python backend/tests/benchmark_dedup_v2.py`，需本地 FFmpeg 和可用硬件编码器；所有素材/缓存/结果均位于测试临时目录，结束自动清理，stdout 输出 JSON。此脚本不纳入普通 pytest，也不改变软件保存的配置。

前端 Vite 构建和 runtime/UI 回归验证有效；工作区另有未跟踪的 `GovernancePanel.tsx` 实验文件，完整 `tsc --noEmit` 的既有类型错误不属于本次修改，未将该实验接入应用。macOS 尚未在本机实测，待实际发版 CI 与设备验收。
