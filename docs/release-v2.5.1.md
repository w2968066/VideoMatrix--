# VideoMatrix 2.5.1

- 修复随机首帧取样靠后时缓存大量前段画面的问题：独立定位取帧，降低高分辨率并发时的内存峰值。
- GPU 编码增加跨任务统一并发预算；暂时 CUDA/资源错误先等待在途编码释放，再单路有限重试，避免一次封面失败让整个任务一直降级 CPU。
- 瞬时探测失败不再长期缓存为 GPU 不可用；错误日志优先展示具体根因，完整 FFmpeg 错误保存在用户配置目录的 `VideoMatrix/logs` 中，最多保留 20 份。
- 修正智能压测的实际并发数量与会话释放；硬件速度测量不再计入等待时间，避免错误选择编码器。
- 明确显示基础混剪、封面处理、最终完成；后处理失败或停止时将保留视频列入产出并显示原因。任务区分全部完成、部分完成和失败。
- 封面探测支持超时和取消；保持替换首帧原帧数、插入首帧增加一帧及全部音频整体后移的规则。
- 安装包仅包含正式程序输出目录，排除开发截图、测试日志等文件。
