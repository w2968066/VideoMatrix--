# 目录浏览与文件管理（v2.5.0）

- 缩略图、列表、详细信息；按名称、修改时间、类型、大小升降序排序，文件夹优先。
- 系统原生缩略图按可见范围加载，不调用 FFmpeg；列表、详细信息仅显示小图标。
- 收藏当前目录、移除收藏；视图、排序、收藏保存在独立的本地配置，不改变混剪参数。
- 新建文件夹：在当前目录创建，不复用或覆盖同名项目。
- 双击目录进入，双击文件交给默认软件；可执行文件或外部链接需再次确认。
- 右键或“操作”：打开、系统文件管理器定位、复制完整路径、重命名、移入回收站。
- Ctrl / Command 切换管理选中，Shift 连选，Ctrl / Command+A 选中当前筛选结果（最多 500 项）。文件管理选中与 Body 素材勾选分开。
- 后退、前进支持 Alt+左右方向键；F5 刷新，F2 改名，Ctrl / Command+C 复制路径，Delete 移入回收站，Shift+F10 打开菜单。
- 重命名文件只编辑主名称并保留扩展名。目标已存在则失败，不覆盖；仅大小写不同的改名交给原生文件管理器。
- 删除前显示目标数量和完整路径，默认取消；仅使用系统回收站，失败不转为永久删除。部分失败会保留失败项目并显示原因。
- 混剪运行或排队时禁止改名和删除；主进程执行前再次向自己的后端核验，后端不可用也会阻止。确认删除后、每个项目操作前重新核验。
- 用户主目录、软件目录、配置目录及包含它们的上级目录禁止改名和删除。
- 改名成功后同步软件配置中受影响的素材路径、输出路径、收藏与目录勾选；删除成功后移除相关引用。其他参数不变。
- Esc 先取消当前新建/改名输入，再退出选择窗口；文件操作过程中禁止关闭窗口。

复制、移动和复杂批量改名仍使用系统文件管理器。本地 Windows 测试覆盖真实桌面 IPC 和原生改名；macOS 需要后续在 Mac 上验证。
