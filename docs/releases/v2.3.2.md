# VideoMatrix 2.3.2

本次更新修复端口冲突、前后端版本混用和加速日志不显示，并包含 2.3.1 本地测试版的硬件编码改进。

## 修复与优化

- 自动使用系统分配的本机空闲端口，避免固定 8765 端口与其他软件冲突。
- 启动时核验前后端版本和本次启动身份；后端缺失、版本不符、启动超时或异常退出时明确提示。
- 关闭窗口时停止任务并清理本实例的后台进程；桌面异常退出时后端会监听连接断开并退出。
- 修复真实渲染日志未接入界面的问题；右侧日志现在显示硬件编码、CPU 降级和底层失败原因，清空后不重复回放旧日志。
- 混剪、成品变换、随机封面共用硬件编码会话。Windows 探测 NVIDIA / Intel / AMD 编码器，macOS 尝试 VideoToolbox；硬件不可用时显示原因并继续 CPU 编码，资源不足时降低并发重试。
- 优化长素材裁切定位，减少重复编码，并修复已合并的成品变换被再次执行的问题。
- 智能压测隔离正式素材历史，只统计成功任务，并包含开启的后处理阶段。
- 本地 Agent 接入支持发现桌面动态端口并核验后端身份。

## 使用方法

1. 退出旧版后安装新版，窗口标题应显示 **VideoMatrix 2.3.2**。
2. 正常选择素材并勾选 **GPU**，启动渲染；无需手动设置端口。
3. 在右侧 **日志** 查看 `[加速]` 和 `[加速降级]`。遇到速度异常，复制这些日志反馈即可。

硬件编码仍受显卡、驱动和素材影响；字幕等软件滤镜可能继续使用 CPU。此次更新不承诺所有设备都能启用 GPU 或固定倍数提速。

## 安装包

- Windows：`VideoMatrix.Setup.2.3.2.exe`
- macOS：`VideoMatrix.Setup.2.3.2-mac.dmg`

安装包内置后端、FFmpeg / FFprobe 和思源黑体，无需自行安装 Python。
