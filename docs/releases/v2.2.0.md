# VideoMatrix 2.2.0

## Body 分组

- Body 支持普通 / 分组模式。
- 分组模式最多 4 组，每组可独立选择文件夹、随机抽取片段数和单片段时长。
- 输出顺序固定为 `Hook → Body 1 → Body 2 → Body 3 → Body 4`，每组内部随机抽取。
- 自动显示包含 Hook 的总片段数和预计总时长；普通模式的原有设置会保留。
- 分组目录不存在或素材不足时，预检会指出具体分组，不会静默跳过。

## 随机首帧

- 新增独立“随机首帧”开关，与成品变换开关互不依赖。
- 每条成品从自身随机抽帧并随机缩放裁切，不输出额外 JPG。
- “替换首帧”保持原时长和帧数。
- “插入一帧”将封面帧放在视频最前面，音频同步后移一帧，时长增加 `1 / 输出帧率` 秒。
- 处理失败或任务取消时保留原成片。

## 验证

- 后端测试 29 项通过，覆盖分组时长、分组不足提示、24fps / 29.97fps 两种首帧模式、音频与帧数校验、取消任务及组合流程。
- Electron 界面回归和字幕滑杆回归通过。
