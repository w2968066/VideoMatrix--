# VideoMatrix 2.1.0

## 新功能

- 新增可选“去重变换”成品处理层，关闭时不改变原有混剪流程。
- 新增“轻度 / 标准 / 增强”三档强度及切换提示。
- 每个输出和内部片段使用独立随机参数，源 Hook、Body 不会被修改。
- 浏览按钮会从对应行的当前目录或上次打开目录开始。

## 使用方法

1. 正常设置 Hook、Body、BGM、输出目录与混剪参数。
2. 打开右侧“去重变换”，开启开关并选择强度。
3. 启动渲染；软件会先完成原有混剪，再处理最终成品。
4. 变换失败时自动保留原混剪成品，整批任务继续执行。

## 修复与改进

- 修复 Windows 文件占用导致 `.variant-*.mp4` 残留、实际目录文件数超过设定产量的问题。
- 中间文件改为非视频扩展名，并增加替换重试与失败清理。
- 修复旧版随机镜像配置可能在新版中被隐藏继承的问题。
- 修正“仅 Body 生效”按钮的含义和提示。
- 改进预检运行状态、并发参数校验和错误反馈。

> 成品变换是本地创意处理功能，不承诺任何平台的“首发”或识别结果。
