# VideoMatrix 2.1.4

## 字幕字体、字号与交互预览

- 内置思源黑体 Source Han Sans SC Regular，SRT 烧录统一使用该字体，无需用户另行安装。字体及 SIL OFL 1.1 许可随安装包分发。
- 新增字幕字号滑杆，范围为画面高度的 3%–9%，默认 5.6%；提供“小 / 标准 / 大”快捷设置，字号随配置保存。
- 修复界面缩放后鼠标点击位置与滑杆竖线错位的问题，位置与字号滑杆均已修正。
- 按住任一字幕滑杆时显示极简悬浮预览，实时展示字幕相对位置、大小与画面比例；松开、取消拖动或窗口失焦即隐藏。
- 预览使用 10 个中文字“这是十个字的字幕示例”，字号较大时自动换行。预览为示意，不是实际视频帧；真实字幕长度与排版以成品为准。

## 使用方法

1. 选择 SRT 字幕目录，确认字幕为“已开启”。
2. 用顶部 / 中央 / 底部预设或位置滑杆调整字幕位置。
3. 用小 / 标准 / 大预设或字号滑杆调整大小；按住滑杆查看即时示意。
4. 启动渲染，软件按当前设置将字幕烧录到成品；SRT 原文件不变。
